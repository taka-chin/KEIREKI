# 職務経歴書・履歴書 作成ツール

ブラウザで動く職務経歴書・履歴書の作成ツールです。  
入力内容はブラウザ内で完結し、サーバーに送信されません。

## 起動方法

### Docker Compose（推奨）

```bash
docker compose up -d
```

ブラウザで http://localhost:8080 を開く。

### Docker のみ

```bash
docker build -t resume-builder .
docker run -d -p 8080:80 resume-builder
```

### 停止

```bash
docker compose down
```

## 使い方

1. 上部タブで **職務経歴書** / **履歴書** を切り替える
2. 各項目を入力（職歴は「職歴を追加」で複数追加可）
3. 職歴の会社名横にある **HP検索** で企業の公式サイトを検索
4. 右側の **PDFプレビュー** で内容を確認
5. **印刷でPDF保存** ボタンで印刷画面を開き、送信先で「PDFに保存」を選択
6. 必要に応じて **HTMLを出力** ボタンで印刷用 HTML ファイルを保存

デスクトップでは入力フォームの右側にプレビューが常時表示されます。画面幅が狭い場合は、フォームの下に表示されます。

職務経歴書の職歴欄は、会社概要、案件名、プロジェクト概要、担当フェーズ、業務内容、実績、開発環境、規模を入力すると、表形式の経歴欄として出力されます。同じ会社の中で **プロジェクトを追加** を押すと、案件ごとの行を増やせます。テクニカルスキルは、種類、スキル名、使用期間、レベルを行ごとに入力して表形式で出力できます。各スキルは **スキルを更新** と **スキルを削除** で操作できます。**プロジェクトから自動作成** を押すと、各プロジェクトの担当期間と開発環境からテクニカルスキルの下書きを作成できます。

## 下書きの自動保存

入力内容はブラウザ内の `localStorage` に自動保存されます。ページを再読み込みしても、基本情報、職歴、学歴、テンプレート設定が復元されます。保存済みの下書きを消す場合は、画面下部の **下書きを削除** を押してください。

PDFテンプレートはファイル本体を保存せず、PDFテンプレート形式を選んだ状態だけを保存します。

## 生成物の Git 管理

出力された HTML/PDF には氏名、住所、連絡先、職歴などの個人情報が含まれます。生成した履歴書・職務経歴書、確認用画像、一時ファイルは Git にコミットしないでください。ローカルで保管する場合は、リポジトリ外のダウンロード先や一時フォルダを使用してください。

テンプレートとして共有する PDF/HTML/TXT を追加する場合は、実在の個人情報や応募先情報を含めず、サンプルデータだけにしてください。

### テンプレート

職務経歴書と履歴書では PDF、HTML、TXT テンプレートをアップロードできます。PDF をアップロードした場合は、PDFを直接編集せず、同じ用途の白黒A4レイアウトで出力します。

HTML または TXT テンプレートでは以下のプレースホルダーを使用できます。

```html
{{today}}
{{name}}
{{nameKana}}
{{birthday}}
{{phone}}
{{email}}
{{address}}
{{contacts}}
```

職務経歴書では以下も使用できます。

```html
{{summary}}
{{works}}
{{technicalSkills}}
{{skills}}
{{careerPr}}
```

履歴書では以下も使用できます。

```html
{{education}}
{{resumeWorks}}
{{motivation}}
```

例:

```html
<h1>職務経歴書</h1>
<p>{{today}}</p>
<h2>{{name}}</h2>
<section>{{summary}}</section>
<section>{{works}}</section>
<section>{{technicalSkills}}</section>
<section>{{skills}}</section>
<section>{{careerPr}}</section>
```
